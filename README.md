# Jev 求职助手（Android 私用 APK）

面向手机 BOSS 直聘当前打开的职位：读取 JD，推荐本地 PDF 简历，生成招呼语和 HR 回复候选。所有文案都由用户核对、编辑、复制并手动发送。

## 构建和安装

要求 JDK 17、Android SDK 34。执行：

```bash
export ANDROID_HOME="$HOME/Library/Android/sdk"
./gradlew testDebugUnitTest assembleDebug
"$ANDROID_HOME/platform-tools/adb" install -r app/build/outputs/apk/debug/app-debug.apk
```

APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。项目只生成调试签名 APK，供个人侧载；没有发布签名或应用商店配置。

## 首次使用

1. 填入自己的 TypeSafe/Jev 和 DeepSeek API 密钥。需要推荐简历或生成招呼语时，再导入文字版 PDF 简历。密钥经 Android Keystore 加密；请勿在聊天或截图中发送密钥。
2. 按应用中的入口手动开启读屏服务与悬浮窗权限，再点“打开 BOSS 直聘”。
3. 打开职位详情，逐屏稍停并手动滚动阅读 JD。点“荐”悬浮按钮，核对读到的职位文字与 OCR 补读次数；需要时点“补读当前屏幕”。分析简历、生成招呼语前先检查脱敏发送预览。
4. 在 HR 聊天页点悬浮按钮，直接选顶部“HR 对话回复”。核对可见聊天和最新 HR 消息，可直接选一份已导入简历作为背景。先点击“拆解 HR 消息中的问题”，核对并编辑问题清单；需要你的个人事实时填写准确答案，不确定可留空让助手澄清。确认清单后再生成回复。每次调用前检查脱敏发送预览；若 Jev 建议无需回复，可结束或明确选择继续生成。
5. 修改候选回复后点“复核并复制”。Jev 会检查每个问题是否得到回答或合理澄清，以及未经确认的事实、时间或薪资承诺。出现提示时可返回修改，也可在人工核对后继续复制；发送仍由你手动完成。

## 数据边界

- 只读取 BOSS 直聘在前台时当前可见的界面；对当前页面进行本机截图 OCR 补读，不上传截图。不会自动滚动聊天、自动发送或投递。
- 只有点击分析或生成时才调用远程 API。简历及聊天中的常见联系方式和证件号先脱敏，仍应在生成前人工检查输入是否含其他敏感信息。原始聊天只保留在内存；PDF 提取的文字由 Android Keystore 加密后保存在应用私有目录，删除简历可移除相应内容。旧版未加密的简历库会在首次读取时迁移。
- 复制的文字会进入系统剪贴板；应用会在两分钟后尝试清除仍未变化的复制内容。切换聊天或岗位时会清除旧候选；请求期间页面变化会丢弃旧结果。
- 当前 BOSS 页面结构、文字识别结果和模型判断都可能出错。发送前必须核对 JD、推荐依据及文案中的事实。扫描版 PDF 会提示使用文字版。
- HR 回复以你确认的最新 HR 消息为主，当前可见聊天作背景；Jev 会对候选做概率性事实与话题初筛，不能替代人工核对。匹配依据展示 JD 和简历原文摘录，不代表一定满足岗位要求。
- 问题拆解由 DeepSeek 完成，最多列出十项；你可以修改、删除或补充。拆解和最终复核都属于模型判断，可能误判，请核对原始 HR 消息及你实际发送的文案。
- 生成请求可取消等待，但已经发出的 API 请求可能仍在服务端处理并计费。事实初筛可能只保留少于三条候选。发送预览只展示数据字段，服务提示词和生成候选也会参与相应请求。

## 自行真机验收重点

- 在聊天页切换到另一位 HR，确认旧候选消失；生成途中切换页面，确认旧结果不会显示到新会话。
- 核对“待回复 HR 消息”的说话人和整段可见上下文；手动改写聊天后重新确认。试用键盘输入，确认悬浮面板不被键盘关闭。
- 切换岗位并滚动，核对 JD 没有混入前一个岗位；遇到“暂停累计”时选择确认同一岗位或清空重读。
- 连续快速滚动后核对 OCR 补读次数和 JD，必要时逐屏停留或点“补读当前屏幕”。在回复页直接选择一份简历，并核对发送预览与“无需回复”分支。
- 用一条包含多个问题的 HR 消息核对拆解清单；分别试用已填写和留空的个人事实。修改候选回复后点复核，核对漏答或未经确认承诺的提示，再决定是否复制。
- 检查无法读屏、OCR 失败、缺少密钥、API 失败和扫描版 PDF 的提示。完成这些真机操作前，不能视为已验证。

## API

- Jev：`POST https://api.typesafe.ai/v1/systemone`，模型 `jev-latest`，负责简历匹配分数和 HR 消息意图判断。
- DeepSeek：`POST https://api.deepseek.com/responses`，模型 `deepseek-flash`，负责生成 JSON 格式文案候选。

两个服务均由手机通过 HTTPS 直连，使用用户自己填写的密钥。服务无后台服务器，也不采集账户密码。

主界面的“诊断 Jev 连接”只发送一条固定的最小测试请求，不包含 JD、简历或聊天内容。诊断中的 GET 返回 HTTP 405 表示域名可达，因为该接口只接受 POST。若 POST 在建立连接时超时，应用会自动重连一次；仍失败时可切换 Wi-Fi/移动网络再试。HTTP 429/529 会有限次退避重试；请求已发送后的读取超时不会自动重试，以免重复计费。余额正常不能排除手机到 API 的网络超时。
